How I counted: I wrote a CSV parser in perl (handles quotes, doubled quotes, commas and newlines inside quotes, CRLF endings and a UTF-8 BOM) and piped it to perl. Every table uses CRLF, and the number of CRs equals the number of LFs in every file, so no record spans two lines. That means record n is always physical line n+1. All row references below are physical file line numbers, with the header on line 1. "Duplicates" means extra byte-identical copies after parsing, not counting the first occurrence. Every table's size matches the size listed in its own .md "Experimental table" row (for example FLEX 24,776 B = 24.2 KB, FLEX-2 1,029 B = 1.0 KB, CFI-G 39,422 + 22,166 B = 60.1 KB). So these look like the original PSI files, with none swapped.

=== B. Reconciling the earlier claims ===
Investigations, 24 versus 19: the JSON has exactly 24 records, all with Research Area "Combustion Science". The 19 folders match 19 "Microgravity Investigation" records. The other 5 are "Ground Investigation" records with no acronym and no experiment table in the harvest:
- PSI-117 (CFD of cool flames, related to PSI-69 and PSI-142)
- PSI-62 (flame spread modelling against BASS)
- PSI-60 (SPICE data analysis)
- PSI-142 (counterflow cool flames)
- PSI-115 (SAME smoke modelling)
README.md says these 5 were excluded on purpose. It also lists PSI-181 and PSI-108 as excluded, but neither is in the JSON.

Tables, 22 versus 21: index.csv experiment_table_files adds up to 21 (CFI-G 2, Flame Design 2, the other 17 folders 1 each), and there are 21 files on disk.

Rows, 2,009 versus 2,001: the review's 2,001 is reproduced exactly as 2,862 parsed records minus the 861 blank CFI-G Inverse records. That count still includes the 50 duplicates and excludes the 21 headers.
The original's 2,009 is 8 more, with 1 more table. The simplest fit is one extra table with exactly 8 data rows. Only two tables have exactly 8 data rows: FLEX-2 (PSI-68) and SAME (PSI-102). So "the FLEX-2 table counted twice, or a duplicate FLEX-2 file" fits both differences exactly.
The other explanations do not fit:
- A copy of the FLEX table mislabelled FLEX-2 would add 274 rows, not 8. The FLEX-2 file on disk has its own 8-row summary structure and matches PSI's 1.0 KB listing.
- Counting header rows would add 21 or 22, not 8.
- Counting the CFI-G blank rows would add 861.
- Removing the duplicates (8 E-FIELD, 8 CFI or 34 SPICE) would make the review lower than 2,001, not explain a higher original.
Unexplained: I could not see the original harvest's manifest, so which 22nd table it held is unconfirmed. The 8-row coincidence is the only exact arithmetic fit I found.

=== E. Access-gap test (solid fuels) ===
I found no solid-fuel (fabric or plastic) test with a genuine O2 above 23%.
- The solid-fuel tables are BASS-II, BASS, SAFFIRE-I, II and III, SAME, SAME-R, and DAFT (dust).
- BASS-II initial O2 maxes at 22.2; SAFFIRE-I at 21.5-21.7; SAFFIRE-II at 22.1. BASS, SAFFIRE-III, SAME and SAME-R have no O2 column.
- The only cells above 23% are BASS-II final O2 39.1 (line 98, P22b, 3/8" black rod, initial 20) and 40.4 (line 129, T28b, 1 cm SIBAL, initial 20.7). Both are data errors, not test conditions.
- No solid-fuel table has a pressure column, so the "below 1 atm" half cannot be tested from the tables at all.
- Sub-atmospheric or high-O2 conditions appear only for gases and droplets: CFI-G (0.495-0.55 bar), Flame Design (about 0.42-0.52 atm), CFI (0.5 and 0.75 atm), FLEX (526-544 mmHg) and BRE (25-40% O2).
- BRE is a gas burner that emulates solid burning; its .md cites 10.2 psia at 26.5% and 8.2 psia at 34%, but its table records no pressures. It is the nearest thing to a counter-example, but it is not solid fuel.
